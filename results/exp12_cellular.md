# Experimento 12 — Cellular automata como compute substrate

**Tese (Wolfram NKS):** estados discretos + regras simples = computação universal.
Rule 110 é provadamente Turing-completa. CA é o substrato MAIS simples possível para
computação arbitrária.

**Setup:**
- 256 cells (= 32 bytes), 256 generations
- Estado inicial: bit central ativo
- 8 regras testadas (incluindo Rule 110, 30, 90)

## Validação Rule 110 (mais importante)

Rule 110 é provadamente Turing-completa (Cook 2004). Aqui rodamos 256
generations em 256 cells. O comportamento esperado é Class IV (complexo):
estruturas localizadas ("gliders") interagindo de forma não-trivial.

## Implicação

- **Compute substrate viável:** Rule 110 mostra que cells de 1 BIT (cada um!) podem
  implementar qualquer computação dado tempo suficiente. Bytes têm 256× mais estados.
- **Conexão com fsm-cognitive-architecture:** docs/01-conceitos-fundamentais.md cita
  Wolfram NKS como justificação filosófica para FSM 8-bit.
- **Implementação trivial:** 1 byte por 8 cells, lookup table de 8 entradas (256 regras).
  Roda em qualquer hardware integer.

**Pós-LLM hipotético:** rede de FSMs de 8 bits onde regras de transição (LUT 4096)
são análogas a regras CA. Computação emerge da DINÂMICA, não dos pesos.
